# HabTrack 🚀

**HabTrack** est une application mobile de suivi d'habitudes gamifiée conçue avec **React Native** et **Expo**. Transformez votre routine en aventure : suivez vos objectifs, gagnez de l'XP et débloquez des succès au fil de votre progression.

## 📲 Essayer l'application (Android)

Vous pouvez tester l'application directement sur votre smartphone :
1. Rendez-vous dans la section [Releases](https://github.com/Donovan-RD/Habtrack/releases) de ce dépôt.
2. Téléchargez le dernier fichier `.apk`.
3. Installez-le sur votre appareil Android.

---

## ✨ Fonctionnalités principales

* **Système de Gamification** : Progressez à travers des niveaux en gagnant de l'XP à chaque habitude complétée.
* **Types d'habitudes flexibles** : Gérez des habitudes simples (booléennes) ou quantitatives (compteurs avec objectifs précis).
* **Tableau de bord de statistiques** : Visualisez vos performances hebdomadaires et vos records de séries (streaks).
* **Badges et Succès** : Débloquez des trophées basés sur votre régularité et vos accomplissements.
* **Synchronisation en temps réel** : Vos données sont sauvegardées en toute sécurité sur Firebase.
* **Notifications de rappel** : Recevez une alerte quotidienne pour ne jamais oublier vos objectifs.
* **Expérience utilisateur soignée** : Interface moderne incluant un mode sombre et des gestes intuitifs de balayage.

## 🛠️ Stack Technique

* **Framework** : React Native avec Expo.
* **Base de données & Auth** : Firebase (Firestore & Authentication).
* **Gestion d'état** : Context API (Habits, Auth, Theme).
* **Design** : StyleSheet API, Lucide Icons, et Glassmorphism.
